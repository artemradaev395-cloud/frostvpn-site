# BEW FROSTVPN bot prototype

Telegram bot menu prototype built with aiogram 3.

## Run
1. Install Python 3.10+.
2. Install dependencies: `pip install -r requirements.txt`
3. Set `BOT_TOKEN` as an environment variable/hosting secret.
4. Run: `python main.py`

Never commit `.env` or paste your bot token into chats.

## Prototype limitations
The tariff list is informational only. Payments, subscription checks, VPN provisioning,
and automated support tickets are not implemented. The support button opens
https://t.me/frost3920201.
